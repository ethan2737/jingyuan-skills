### 16.1 面向过程

在没有学习面向对象编程之前，我们的开发思路是面向过程的，就是把一件事按照流程一步一步做完，所作的事情都是以流程为核心，例如我们经常写的函数编程：

```python
# 流水账一样
import requests

def send_req(url):
    while 1:
        try:
            resp = requests.get()
            return resp
        except Exception as e:
            print(e)
            
def parse_sth(page_sources):
    return "数据"

def main():
    url ="xxxx"
    # 1. 获取页面源代码
    page_sources = send_req(url)
    # 2. 解析页面源代码
    data = parse_sth(page_sources)
    # 3. 保存数据
    # ....

if __name__ == '__main__':
    main()
```

### 16.2 面相对象

而面向对象的开发思路是一切以对象为核心。怎么来理解对象呢？你可以理解为`对象`就是能帮你干活的`任何事物`。

示例1：要把大象装冰箱，总共分几步？

```python
# 面相过程的思路：
1. 把冰箱门打开
2. 把大象装进去
3. 把冰箱门关上
```

```python
# 面向对象的思路：
大象. 你进冰箱
大象自己去开门
大象自己装自己
大象自己把门关上

在这个逻辑里面. 你只需要找到一个可以帮你完成把自己关进冰箱里的大象就可以了
```

示例：我想喝可乐

```python
# 面向过程:
1. 从沙发上起来. 走到冰箱门口
2. 把可乐拿出来
3. 把冰箱门关上.
4. 回到沙发喝可乐

# 面向对象:
你找个对象
命令你的对象. 去拿可乐.
你的对象. 去冰箱
你的对象, 拿可乐
你的对象, 交到你手里
你, 喝可乐
在这个模型当中, 你只需要找到一个可以帮你拿可乐的对象就可以了.
```

所以在面相对象编程中，你只需要找到一个可以帮你完成某个工作的对象就可以了。还拿女朋友举例子，直接找这样的女朋友找不到的，但是在程序的世界里，你就是上帝，既然没有符合你要求的对象，你可以自己去创造一个符合你要求的对象。

那么如何创建对象呢？

- 首先，创建类，用类来描述你即将要创建出来的对象是什么样的
- 在类里面，你可以定义各种各样的方法，也就是你创建的对象支持什么样的功能，比如做饭、打扫卫生等等
- 语法：

```Python
class 类名:
    # 类里面的东西
    def xxxx():  # 类中的函数, 被称为方法, 是给对象使用的
        pass
# 创建对象:
obj = 类名()
obj.类中定义的方法()
```

```python
# 类是用来描述对象的
# 类又被称为归类. 指的是你对一类事物的总结和归纳
class NvPengYou:
    # 我需要女朋友能帮我拿可乐
    def nakele(self):
        print("我是乖乖的女朋友, 帮你拿可乐去")
    def chi(self):
        print("女朋友喂我吃东西")
    def nuanchuang(self):
        pass

# 创建对象:类名+()
p1 = NvPengYou()
# 指挥对象去干活
p1.nakele()
p1.chi()
```

### 16.3  类的参数 self

在类的方法中经常出现的`self`是什么？是当前正在执行该方法的对象自己。例如：

- 张三.做饭()	self就是张三
- 李四.打扫卫生()  self就是李四

在类中是通过`__init__`方法初始化参数的，在对象被创建的时候，自动执行。


```python
def __init__(self, name, age, shengao):  # 给新创建的对象初始化
    # 当前对象的名字 = 你传过来的名字
    self.name = name
    self.age = age
    self.shengao = shengao
```

```python
class NvPengYou:
    # self就是执行该方法的对象，哪个对象执行的这个方法，self就是谁，它是动态变化的。
    def nakele(self):  # 方法的第一个参数, 是对象本身
        print(id(self))  # 2380120649680
        print("我是乖乖的女朋友, 帮你拿可乐去")

    def chi(self):
        print("女朋友喂我吃东西")

p1 = NvPengYou()
# 在面向对象的世界里. 对象执行某一个方法的时候. 会自动的把该对象作为第一个参数传递给方法
p1.nakele()
```

### 16.4 用面相对象写爬虫

```python
class DouBanSpider:
    def __init__(self, headers):
        # 面向对象对我们普通的爬虫而言, 可以解决全局变量的问题
        # 建立session
        self.session = requests.session()
        self.session.headers = headers
        # 打开文件
        self.f = open("data.csv", mode="w", encoding="utf-8")

    def get_data(self, page):
        url = "https://movie.douban.com/j/chart/top_list"
        params = {
            "type": "13",
            "interval_id": "100:90",
            "action": "",
            "start": (page - 1) * 20,  # 20 40 60 80...
            "limit": "20"
        }

        resp = self.session.get(url, params=params)
        return resp.json()

    def save_data(self, data):
        for item in data:
            title = item['title']
            self.f.write(title)
            self.f.write("/n")

    def start(self, from_page, to_page):
        for i in range(from_page, to_page + 1):
            # 1.拿到数据
            data = self.get_data(i)
            # 2.存储数据
            self.save_data(data)

# 把请求头传进去
db_spider = DouBanSpider(headers)
db_spider.start(1, 3)
```

### 16.5 对象与对象之间的关系

以植物大战僵尸为例说明

```python
# 植物大战僵尸
# 植物
import requests
class Plant:
    def __init__(self, gongjili, xue, name):
        self.gongjili = gongjili
        self.xue = xue
        self.name = name

    def gan_jiangshi(self, jiangshi):  # 传递参数的时候. 是可以把一个完整的对象作为参数传递的
        # 植物打僵尸, 僵尸要扣血
        jiangshi.xue -= self.gongjili
        # 僵尸反击
        jiangshi.gan_zhiwu(self)    # 僵尸可以咬植物, 把植物作为一个参数, 传递出去


# 僵尸
class JiangShi:
    def __init__(self, gongjili, xue, name):
        self.gongjili = gongjili
        self.xue = xue
        self.name = name
    def gan_zhiwu(self, zhiwu):
        zhiwu.xue -= self.gongjili


# 游戏(client)
p1 = Plant(180, 5000, "豌豆")

j1 = JiangShi(10, 10000, "铁通僵尸")
```

### 16.6 继承

子类可以自动拥有父类除了私有内容以外的所有内容

```python
class Father:
    def __init__(self):
        # 永远盯着self是谁... 永远不会乱.
        self.name = "呵呵"
    def chi(self):
        print(self.name, "父在吃")


# Son继承了Father,  也就自动的拥有了父类中的方法
class Son(Father):
    def __init__(self, name):  # 初始化子类的时候. 需要同时初始化父类
        super().__init__()  # 子类里调用了父类的__init__()
        self.name = name

    def chi(self):
        print(self.name, "子在吃")
        # super() 表示找到父类
        super().chi()  # 这里执行的是父类中的方法. 但是传递的还是当前self对象


s = Son("哈哈")
s.chi()  # 子在吃

"""
简单的MRO, 方法的查找路径:
先在对象自身的类中去找. 如果能找到就执行. 如果找不到. 就去父类中去找
"""

```

### 16.7 类变量

直接被定义在类中的变量，官方解释为：类变量。它的本质就是类中的一个属性。Python是纯面相对象的编程语言，万事万物皆为对象。类创建出来的对象是对象，但类本身也是一个对象。类变量的特殊性：

- 用对象可以直接访问
- 对象无法修改它
- 类变量的作用就是在当前类中各种方法均可访问，起到共享的作用

```python
class Person:
    # 类变量
    country = "中国"
    def __init__(self, name):
        self.name = name

    def chi(self):
        print(self.name, self.country, "爱吃东西")

p1 = Person("樵夫")
p1.chi()

print(p1.name)
# 类的属性
print(Person.country)
# 1. 用对象可以直接访问
print(p1.country)
# 2. 对象是改不了它的
p1.country = "俄罗斯"
print(Person.country)
print(p1.country)

Person.country = "老美"
print(p1.country)
```
