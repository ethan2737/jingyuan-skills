### 7.1 RE模块

#### 7.1.1 正则表达式

正则表达式（Regex）是一种 **字符串** 匹配规则，通过特殊符号描述文本模式，用于快速搜索、替换复杂文本；验证数据格式（如邮箱、手机号）；高效提取结构化数据（如网页中的价格、日期）；文本清洗与标准化

##### 7.1.1.1 基础元字符

具有固定含义的特殊字符叫做 **元字符**

| 符号   | 说明                                   | 示例                   |
| ------ | -------------------------------------- | ---------------------- |
| `.`    | 匹配除换行符以外的任意字符             | `a.b`→ "abc"、"a#b"    |
| /d     | 匹配数字，等价于`[0-9]`                | `/d{3}` → "123"        |
| /w     | 匹配字母/数字/下划线（`[a-zA-Z0-9_]`） | `/w+` → "user123"      |
| /s     | 匹配空白符（空格、制表符等）           | `/s+` → " "            |
| ^      | 匹配字符串开头                         | `^Hello` → 开头是Hello |
| $      | 匹配字符串结尾                         | `world$` → 结尾是world |
| /n     | 匹配一个换行符                         |                        |
| /t     | 匹配一个制表符                         |                        |
| a /| b | 匹配字符 a 或 字符 b                   |                        |
| ( )    | 匹配括号内的表达式，也表示一个组       |                        |

##### 7.1.1.2 量词

量词，用来控制前面的元字符出现的次数

| 符号  | 说明                    | 示例                          |
| ----- | ----------------------- | ----------------------------- |
| `*`   | 匹配前一个字符0次或多次 | `ab*c` → "ac"、"abbc"         |
| `+`   | 匹配前一个字符1次或多次 | `ab+c` → "abc"、"abbc"        |
| `?`   | 匹配前一个字符0次或1次  | `colou?r` → "color"、"colour" |
| {n}   | 匹配前一个字符n次       | `/d{4}` → "2023"              |
| {m,n} | 匹配前一个字符m到n次    | `a{2,4}` → "aa"、"aaaa"       |

##### 7.1.1.3 贪婪匹配和惰性匹配

一般情况下，惰性匹配使用的最多，工作原理是首先匹配`.`字符，然后`*`字符开始工作，尽可能多的找出匹配的字符，然后`?`开始工作，经过回溯，找到距离开始最近的那个位置结束，并找出开始到结束这个区间的所有内容。

| 符号  | 说明                                       | 示例            |
| ----- | ------------------------------------------ | --------------- |
| `.*`  | 贪婪匹配，尽可能多的匹配到字符，匹配最长的 |                 |
| `.*?` | 惰性匹配，尽可能少的匹配字符，匹配最短的   | （?P<name>.*?） |
|       |                                            |                 |

##### 7.1.1.4 修饰符

| 修饰符 | 描述                                                         |
| ------ | ------------------------------------------------------------ |
| re.I   | 使匹配对大小写不敏感                                         |
| re.L   | 做本地化识别（locale-aware）匹配                             |
| re.M   | 多行匹配，影响 ^ 和 $                                        |
| re.S   | 使`.`匹配包括换行在内的所有字符                              |
| re.U   | 根据 Unicode 字符集解析字符。这个标志影响 /w、/W、/b 和 /B   |
| re.X   | 该标志通过给予你更灵活的格式以便你将正则表达式写得更易于理解 |

在网页匹配中，较为常用的有 re.S 和 re.I。

#### 7.1.2 Python中的RE模块

导入工具包

```python
import re
```

模块中提供的常用方法如下：`pattern`正则表达式、`string`要匹配的字符串、`r`表示不用对`/`进行转义

| 方法                          | 说明                                                         | 示例                                                 |
| ----------------------------- | ------------------------------------------------------------ | ---------------------------------------------------- |
| re.match(pattern, string)     | **从字符串开头**匹配，返回第一个匹配对象，没有匹配到返回None | `re.match(r'/d+', '123abc') → 匹配 "123"`            |
| re.search(pattern, string)    | **扫描整个字符串**，返回第一个匹配对象，没有匹配到返回None   | `re.search(r'/d+', 'abc123') → 匹配 "123"`           |
| re.findall(pattern, string)   | 返回所有匹配的字符串列表                                     | `re.findall(r'/d+', 'a1b22c3')` → `['1', '22', '3']` |
| re.sub(pattern, repl, string) | 替换匹配的字符串                                             | `re.sub(r'/d+', 'X', 'a1b2') → "aXbX"`               |
| re.split(pattern, string)     | 按正则规则分割字符串                                         | `re.split(r'/d+', 'a1b2c')` → `['a', 'b', 'c']`      |

##### 7.1.3 爬虫必备正则技巧

| 分类         | 作用          | 正则表达式                                 |
| ------------ | ------------- | ------------------------------------------ |
| 提取关键数据 | 匹配url       | `https://[/w./?=&%-]+`                     |
|              | 匹配邮箱      | `[/w.-]+@[/w.-]+/./w+`                     |
|              | 匹配价格      | `￥/d+(/./d{1,2})?` → `"￥199"、"￥59.99"` |
| 处理HTML     | 提取标签内容  | `<title>(.*?)</title>`                     |
|              | 提取属性值    | `<a href="(.*?)">`                         |
| 分页参数提取 | 从url提取页面 | `page=(/d+)` → 从 `page=3` 中提取 "3"      |
| 数据清洗     | 去除HTML标签  | `re.sub(r'<.*?>', '', text)`               |
|              | 删除多余空格  | `re.sub(r'/s+', ' ', text)`                |

```python

# 返回匹配字符的迭代器
re.finditer(pattern, string)

result = re.finditer(r"/d+", "我今年18岁，身高178厘米，我有20000000快钱")

    print(item.group()) # 从内容中提取数据 18、178、20000000，数据均是match对象

# compile 预编译正则表达式，提升性能
pattern = re.compile(r'/d+')
# 直接使用预编译好的正则表达式
result = pattern.findall("我叫周杰伦，今年32岁，我的班级是5年级4班")
print(result) #["32","5","4"]


# 清洗HTML文本
dirty_html = "<p>这是一段<strong>测试</strong>文本。</p>"
clean_text = re.sub(r'<.*?>', '', dirty_html)
print(clean_text)  # 输出 "这是一段测试文本。"

# 替换内容
r = re.sub(r"/d+", "18", "我今年19岁了, 你知道么, 19岁就已经很大了. 周杰伦20岁就得奖了")
print(r)  # 我今年18岁了, 你知道么, 18岁就已经很大了. 周杰伦18岁就得奖了
```

```python
def parse_page_data(html):
    """解析页面数据"""
    # 创建空数据列表
    data_list = []
    # 预编译正则表达式
    pattern = re.compile(
        r'<dd>.*?<i class="board-index.*?">(?P<rank>/d+)</i>.*?'  # 匹配排名
        r'<p class="name">.*?<a.*?title="(?P<name>.*?)".*?>.*?</a>.*?'  # 匹配电影名（通过title属性）
        r'<p class="star">/s*(?P<star>.*?)/s*</p>.*?'  # 匹配主演
        r'<p class="releasetime">(?P<time>.*?)</p>.*?'  # 匹配上映时间
        r'<i class="integer">(?P<score>.*?)</i>.*?'  # 匹配分数整数部分
        r'<i class="fraction">(?P<score1>.*?)</i>.*?</dd>',
        re.S)
    # 把匹配到的结果放在迭代器中
    result = pattern.finditer(html)
    # 循环迭代器拿出结果,已字典的方式拿结果
    for item in result:  # 当测试打印输出内容，控制台为空，第一时间想到反爬问题，处理headers
```

### 7.3 XPath模块

XPath（XML Path Language）是一种查询语言，用于在`XML` 或 `HTML` 文档中导航和选择节点。它通过路径表达式定位节点，并支持打杂的条件筛选、逻辑运算符和函数。

#### 7.3.1 XML简述

```python
# 简述XML概念
<book>
    <id>1</id>
    <name>野花遍地香</name>
    <price>1.23</price>
    <author>
        <nick>周大强</nick>
        <nick>周芷若</nick>
    </author>
</book>
# book、id、name、price都被称为节点
# id、name、price被称为book的子节点
# book被称为是id、name、price的父节点
# id、name、price被称为是同胞节点
```

#### 7.3.2 XPath的安装与导入


#### 7.3.3 基本用法

路径表达式和常用函数

| 表达式           | 说明                                                         |
| ---------------- | ------------------------------------------------------------ |
| `/`              | 从根节点开始（绝对路径）`/html/body/div/p`                   |
| `//`             | 从任意位置开始匹配(相对路径) `//div[@class='content']/p` 忽略层级，直接匹配符合条件的 `div` 下的所有 `p` |
| `./`             | 从当前节点开始匹配                                           |
| `.`              | 选取当前节点                                                 |
| `..`             | 选取当前节点的父节点                                         |
| `@`              | 选择属性                                                     |
| `*`              | 通配符                                                       |
| `[n]`            | 第n个元素（从1开始）                                         |
| `//div/child::p` | 轴操作，选择当前节点的子节点 `p`                             |
|                  |                                                              |
|                  |                                                              |
| **常用函数**     | **作用**                                                     |
| text()           | 获取节点文本，返回列表，取值 `[0]`                           |
| contains()       | 模糊匹配属性值  `//[contains(@class, "li") and contains(@name, "a")]` |
| starts-with()    | 匹配属性前缀`//title[starts-with(., 'Hello')]`   选择以 `Hello` 开头的 `title` 文本 |

通过xpath提取到的内容，不论多少，都是列表。

```python
# XPath 执行流程
  1. 发送请求，获取网页HTML字符串
  2. 构建树结构，使用 etree.HTML() 将HTML字符串 转换为 Element 对象
  3. 编写xpath表达式
  4. 执行查询，调用.xpath()方法返回匹配结果
  5. 遍历列表并提取所需数据


from lxml import etree

xml = """
<book>
    <id>1</id>
    <name>野花遍地香</name>
    <price>1.23</price>
    <author>
        <nick class="jay">周大强</nick>
        <nick>周芷若</nick>
    </author>
</book>

"""
# 初始化XML/HTML文档，获取节点对象，就是把文档中的内容解析出来，放在tree这个对象中，在通过xpath方法，从这个对象中取出数据
tree = etree.XML(xml)

result = tree.xpath("/book/name/text()") # 解释：根节点book下面的子节点name里面的文本内容
result = tree.xpath("/book/name/text()")[0] # text()表示取文本，返回的内容是列表，所以取第0个
result = tree.xpath("/book/name//text()")[0] # //text() 表示标签下的所有文本内容，包括在下一级别标签内的文本
result = tree.xpath("/book/*/name")# * 表示通配符，就是儿子这层节点谁都行
result = tree.xpath("/book/author/nick[@class="jay"]/text()")# [ ] 表示属性筛选，@属性 = 值
result = tree.xpath("/book/parter/nick/@id")# @属性 可以直接拿到属性值，例如<a href=""></a>里面的href
result = tree.xpath("/book/author/nick[1]/text()")# nick[1] 当有多个标签节点时候，只想拿固定的节点内容，就可以使用位置的方式取值,位置从1开始
```
