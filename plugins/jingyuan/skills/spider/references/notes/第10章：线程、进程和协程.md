## 第10章：线程、进程和协程

---

无论是多进程、多线程或者协程，他们存在的意义是让爬虫的效率变高。但这里存在一个悖论，一般情况下为了不出意外，都是要让爬虫慢下来。所以，多线程、多进程与协程要有选择性的使用。

### 10.1 进程与线程

**进程** 是运行中的程序，每次我们执行一个程序，操作系统就自动的为这个程序准备一些必要的资源（例如：分配一块独立的内存，创建一个能够执行的线程，进程是内存资源，不可执行）。

**线程 **是程序内可以直接被CPU调度的执行单位，是操作系统能够进行运算调度的最小单位。它被包含在进程之中，是进程中的实际运作单位。

**进程和线程之间的关系**：进程是资源单位，线程是执行单位。所以就是用线程去执行进程中的资源。我们运行的每一个程序默认都有一个线程。哪怕是只有`hello world`级别的程序，想要执行，也会有一个线程产生。

#### 10.1.1 多进程与多线程

**多进程：**开启多个程序资源

```python
# 一个程序被运行时，会产生一个主进程

# 导入多进程包
from multiprocessing import Process


def work(name):
    for i in range(100):
        print("主进程中的打印",name,i)


# # 主线程，程序入口
if __name__ = "__main__": 
    # 创建进程(目标函数不能加括号，如果带了括号表示函数的返回值)
    p1 = Process(target=work, args=("进程1",)) # args是元组，当有一个元素时，后面要有逗号
    p2 = Process(target=work, args=("进程2",))
    # 启动进程
    p1.start()
    p2.start()

```

**进程池：**

```python
# 导入进程池包
from concurrent.futures import ProcessPoolExecutor


def work(name):
    for i in range(100):
    	print(name,i)


if __name__ == "__main__":
    # 创建进程池(16个进程)
    with ProcessPoolExecutor(16) as p:
        # 提交任务到进程池，提交2个任务
        p.submit(work,"参数1")
        p.submit(work,"参数2")
```



**多线程：**就是让程序产生多个线程一起执行

```python
# 一个程序被运行时，会产生一个主进程，主进程中会有一个默认的主线程
# 导入多线程包
from threading import Thread


def work(name):
    for i in range(100):
        print("主线程中的打印",name,i)

 # 主线程
if __name__ = "__main__":
    # 创建子线程(目标函数不能加括号，如果带了括号表示函数的返回值)
    t1 = Thread(target=work, args=("线程1",)) # args是元组，当有一个元素时，后面要有逗号
    t = Thread(target=work, args=("线程2",))
    # 启动线程
    t1.start()
    t2.start()
 
```

> 注意：创建线程也需要消耗资源，线程数量不宜太多，一般选择CPU核数 * 2，普通电脑 8-16 个线足矣

多进程的面向对象写法

```python
class MyThread(Thread): # 自定义线程类并继承线程类
    def run(self): # 定义的线程任务
        for i in range(1000):
            print("子线程", i)
            
if __name__ == "__main__":
    t = MyThread() # 创建线程对象
    t.start() # 启动线程
```

**线程池：**装有一堆线程的池子，只要把任务装进去，线程池自动完成任务的调度、线程的监控。使用的场景是下载图片和视频资源。多个线程一起工作，又不过多消耗系统的CPU资源。

```python
# 导如线程池包
from concurrent.futures import ThreadPoolExecutor


def work(name):
    for i in range(100):
    	print(name,i)


if __name__ == "__main__":
    # 创建线程池(16个线程)
    with ThreadPoolExecutor(16) as t:
        # 提交任务到线程池，需要执行几个任务就提交几次
        t.submit(work,"参数1")
        t.submit(work,"参数1")
```

#### 10.1.2 使用场景

进程是单独的独立的程序，当需要多个独立功能的程序时，使用多进程。由于进程和进程之间数据是隔离的，所以，进程之间需要借助队列`multiprocessing`包中的队列`Queue`实现通信。

相同的任务可以选择多线程，会让程序变的非常高效。但是注意：在线程中开进程是没有意义的，线程对资源的消耗比进程低很多。

### 10.2 多进程与多线程案例

**多进程** - 生产消费模型

```python
"""
使用多进程下载斗图图片：
    1.创建两个进程，一个进程负责获取图片地址，另一个进程负责下载图片
    2.进程之间的信息传递依赖队列 Queue
    3.在下载图片的进程中开启多线程下载图片

懒加载：这个案例中有个特点，img标签中的src属性//static.doutupk.com/img/loader.gif?33 并不是真的图片，
而是预先加载的占位图，所以需要注意区分
"""

# 请求库、解析库、线程池、进程池、队列
import requests
from lxml import etree
from concurrent.futures import ThreadPoolExecutor
from multiprocessing import Process, Queue


def get_img_url(q):
    """获取图片url"""
    for page in range(1, 3): # 处理分页
        url = f"https://www.doutupk.com/article/list/?page={page}"
        headers = {
            "user-agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/134.0.0.0 Safari/537.36",
        }
        resp = requests.get(url, headers=headers)
        tree = etree.HTML(resp.text)
        img_src = tree.xpath("//div[@class='col-xs-6 col-sm-3']/img/@data-original")    # 找出所有的img地址
        for src in img_src:     # 循环取出每一个src
            q.put(src)     # 逐一放入队列中
    q.put("over")   # 标识符，无数据放入队列


def img_process(q):
    """下载图片的进程"""
    with ThreadPoolExecutor(10) as t:   # 开启10个线程池
        while 1: # 循环取数据
            url = q.get() # 取出的数据赋值给URL
            if url == "over": # 检查标识符
                break
            t.submit(download_img, url) # 提交任务到线程池，执行下载


def download_img(url):
    """下载图片功能"""
    headers = {
        "user-agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/134.0.0.0 Safari/537.36",
    }
    resp = requests.get(url, headers=headers)
    file_name = url.split("_")[-1]      # 对URL切割处理，取最后一个作为文件名
    with open("./img/" + file_name, mode="wb") as f:    # 这里记住一个操作，鼠标右键文件夹 -> mark Dircetory as -> exclusion
        f.write(resp.content)
    print("一张图片下载完成！")


if __name__ == '__main__':

    q = Queue()  # 装载队列
    # 创建2个进程
    q1 = Process(target=get_img_url, args=(q,))  # 第一个进程负责提取图片
    q2 = Process(target=img_process, args=(q,))  # 第二个进程负责下载图片
    # 启动进程
    q1.start()
    q2.start()
    # 等待进程,等待子进程执行完，继续执行主进程
    q1.join()
    q2.join()

    print("下载完成！")

```

```python
# 请求库、解析库、线程池

def str_tool(lst):
    """处理字符串"""
    if lst:
        s = "".join(lst)    # 列表拼接成字符串
        return s.strip()    # 去掉两端的空白符并返回
    else:
        return ""           # 如果列表为空则返回空

def get_movie_info(year):
    """获取电影信息"""
    f = open(f"{year}.csv",mode="w",encoding="utf-8")
    url = f"http://www.boxofficecn.com/boxoffice{year}"
    headers = {
        "user-agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/134.0.0.0 Safari/537.36",
    }
    resp = requests.get(url, headers=headers)
    tree = etree.HTML(resp.text)
    trs = tree.xpath("//table/tbody/tr")[1:]        # 获取到所有的tr，并放入列表trs中
    for tr in trs:                                  # 循环遍历列表中的每一个tr

        year = str_tool(year)
        name = str_tool(name)
        box_office = str_tool(box_office)
        f.write(f"{num},{year},{name},{box_office}/n")  # csv文件要用逗号分割，写入文件中，注意最后的换行
```

### 10.3 协程

**需要重点掌握协程，协程可以完成多任务异步爬虫**

#### 10.3.1 定义

爬虫程序，因为网络请求和等待响应、文件读写等大量`I/O（I/O：是指输入和输出）`操作，使`CPU`大部分时间都处于等待状态。而`CPU`在等待状态的时候，是不为你工作的。所以单线程并没有发挥出`CPU`所有的性能。

**协程** 是单线程中用户态轻量级的操作单位，共享线程资源。在任务执行过程中，只要遇到`I/O`阻塞时，就将阻塞的任务挂起，切换到其他任务继续执行。如果再次遇到`I/O`阻塞，再次挂起、切换。以此类推，最大限度的利用线程计算资源。所以，在多任务、文件读写、网络请求等场景下可以使用协程。

在协程中，通过事件循环`event_loop`来监测任务的切换，决定谁来执行任务。相当于一个巡逻员，逐一观察各个任务的状态，发现任务被阻塞了，就将它挂起，发现该任务阻塞结束了，就将该任务继续执行。

#### 10.3.2 组件

| 组件          | 作用                               | 示例                  |
| ------------- | ---------------------------------- | --------------------- |
| async / await | 定义协程函数和等待异步操作         | async def func():…    |
| Event Loop    | 事件循环，驱动协程执行的核心引擎   | asyncio.run(main())   |
| Task          | 任务，协程的包装对象，用于并发调度 | asyncio.create_task() |
| Future        | 代表异步操作的最终结果             | 通常隐式使用          |

#### 10.3.3 基本语法

```python
# 使用协程的逻辑是固定

# 导包
import asyncio

# 通过async关键字定义异步任务函数1
async def func1():
    print("我是任务1，开始了")
    # 使用await让出当前任务的控制权，让事件循环调度其他任务，模拟任务挂起3秒钟，挂起结束后回来继续执行。
    await asyncio.sleep(3) 
    print("我是任务1，结束了")
    
# 通过async关键字定义异步任务函数2
async def func2():
   print("我是任务2，开始了")
   await asyncio.sleep(5) 
   print("我是任务2，结束了")

# 通过async关键字定义异步任务函数3
async def func3():
   print("我是任务3，开始了")
   await asyncio.sleep(1) 
   print("我是任务3，结束了")

# 异步主任务
async def main():
    # 调用3个异步函数，创建三个协程对象f1/f2/f3，此时await之前的代码会执行，但是不会执行await后面的代码
    f1 = func1()
    f2 = func2()
    f3 = func3()
    # 把三个协程对象封装成任务对象（task），任务对象会被事件循环调度，并发执行
    t1 = asyncio.create_task(f1)
    t2 = asyncio.create_task(f2)
    t3 = asyncio.create_task(f3)
    # 把任务对象都放在一个任务列表中
    tasks = [t1, t2, t3]
    # 统一进行等待三个任务的结束，这里的await其实是阻塞main继续执行，等待所有任务完成
    await asyncio.wait(tasks)
    # 三个任务都结束后，输出信息
    print("任务全部结束")

# 程序入口
if __name__ == "__main__":
    # 调用执行主协程main()，启动事件循环Event Loop，自动调度tasks任务列表中的任务，并在其完成后关闭事件循环
    # 注意：main需要带括号，asyncio要求是协程对象
    asyncio.run(main())

```

```python
     result,pending = await asyncio.wait(tasks)
```


asyncio.run() 和 event_loop.run_until_complete()的比较

| 方法                            | 事件循环管理                 | 弃用风险          | 代码简洁性               |
| ------------------------------- | ---------------------------- | ----------------- | ------------------------ |
| asyncio.run()                   | 自动创建、运行、关闭事件循环 | 无（推荐）        | 高（一行代码）           |
| event_loop.run_until_complete() | 手动获取并管理事件循环       | 有（Python3.10+） | 低（需处理循环生命周期） |

#### 10.3.4 协程使用场景

协程，最适合的场景是下载网站的静态资源，例如：图片、视频、音频，一般这种资源是没有反爬虫的逻辑在的，但有时候也是存在的，例如视频的加密。

### 10.4 进程、线程与协程总结

|   维度   | 进程                                                   | 线程                                               | 协程                                           |
| :------: | :----------------------------------------------------- | :------------------------------------------------- | :--------------------------------------------- |
| 资源分配 | 操作系统分配独立内存和资源                             | 共享进程内存，独立栈空间                           | 用户态轻量级，共享线程资源                     |
| 切换开销 | 大                                                     | 中                                                 | 极小                                           |
| 并行能力 | 多核并行                                               | 收GIL限制                                          | 单线程内并发（无法跨核）                       |
| 数据共享 | IPC（管道/共享内存）                                   | 直接共享进程内存（需要同步）                       | 天然共享（无需同步）                           |
|  容错性  | 进程崩溃不影响其他进程                                 | 线程崩溃可能导致整个进程退出                       | 协程异常仅影响当前任务链                       |
| 典型应用 | 独立程序                                               | 后台任务                                           | 高并发网络服务                                 |
| 场景建议 | CPU密集型任务、需要隔离的独立任务、需要充分利用多核CPU | IO密集型任务、需要快速响应界面操作、轻量级后台任务 | 超高并发网络服务、异步编程模型、事件驱动型任务 |
